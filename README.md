# Firefox Custom Homepage (صفحه خانگی و داشبورد شخصی فایرفاکس)

داشبورد شخصی‌سازی شده، بسیار زیبا، مدرن و پرسرعت برای مرورگر فایرفاکس (یا سایر مرورگرها) ساخته شده با **React 19**، **Tailwind CSS v4** و **Vite**.

این پروژه نسخه خام و آماده شخصی‌سازی است و به صورت پیش‌فرض بدون بوکمارک ارائه شده تا بتوانید سایت‌ها و ابزارهای دلخواه خود را در آن تعریف کنید.

---

## ✨ امکانات و قابلیت‌ها

- ⚡ **اکوسیستم یکپارچه Autofill:**
  - ویجت اختصاصی Autofill با **دو تب مجزای مرورگر و دسکتاپ ویندوز**.
  - همگام‌سازی بلادرنگ با اکستنشن مرورگر و پالت شناور دسکتاپ.
  - **[autofill-extension](https://github.com/mohrezkhorasani/autofill-extension)**: اکستنشن مرورگر جهت پر کردن خودکار هوشمند.
  - **[win-autofill](https://github.com/mohrezkhorasani/win-autofill)**: پالت شناور دسکتاپ با میانبر `Alt + V`.
- 🗂 **تحلیل درختی و شاخه‌ای دیسک (Disk Tree Analyzer):**
  - مودال تمام‌صفحه برای شناسایی فولدرهای حجیم و ترافیک دیسک.
  - ناوبری شاخه به شاخه با نوار Breadcrumb کلیک‌پذیر و باز و بسته‌شدن درون‌خطی پوشه‌ها.
- 🌤 **آب و هوا و پیش‌بینی ۷ روزه:** نمایش دمای زنده، وضعیت جوی و پیش‌بینی یک هفته آینده به صورت فشرده و مرتب.
- 📅 **تقویم سه‌گانه زنده:** نمایش همزمان تاریخ شمسی، قمری و میلادی به همراه ساعت دقیق دیجیتال.
- 🕌 **اوقات شرعی شهر قم:** محاسبه دقیق و زنده بر اساس متد مؤسسه ژئوفیزیک دانشگاه تهران (اذان صبح، طلوع، ظهر، غروب، مغرب، نیمه‌شب شرعی).
- 🌐 **تشخیص و نمایش دوگانه IP:** نمایش آی‌پی اینترنت ایران و آی‌پی سرور خارجی (VPN) همراه با پرچم کشور.
- 🔖 **مدیریت کامل بوکمارک‌ها:**
  - امکان افزودن، ویرایش و حذف بوکمارک‌ها.
  - پشتیبانی از آیکون‌های Lucide، FontAwesome و لوگوی اختصاصی با لینک عکس (Image URL).
  - انتخاب رنگ دلخواه کارت با پالت Color Picker زنده روی هر بوکمارک.
  - نمایش نام کامل بوکمارک در استیکی بج هنگام هاور ماوس.
  - باز شدن لینک‌ها در همان تب مرورگر.
- 🏷 **دسته‌بندی تگ‌ها (Tags Filter):** منوی تک‌ستونه عمودی در سمت راست با رنگ‌های اختصاصی برای هر تگ جهت فیلتر سریع بوکمارک‌ها.
- 📑 **پشتیبانی از صفحات متعدد (Multi-Page):** منوی دسترسی سریع در پایین سمت چپ با امکان تعریف صفحات جدید (مثل Home, Tools و ...).
- 🖼 **تغییر تصویر پس‌زمینه:** دارای ۳ والپیپر جذاب و باکیفیت و دکمه تعویض سریع پس‌زمینه در گوشه بالا.
- ⚡ **فوق‌العاده سریع و بهینه:** بهینه‌سازی شده بدون افکت‌های سنگین گرافیکی تا اسکرول صفحه کاملاً ۶۰ فریم و روان باشد.

## 🚀 نصب و راه‌اندازی سریع

### پیش‌نیازها
- نصب [Node.js](https://nodejs.org/) (نسخه ۱۸ به بالا)

### مراحل راه‌اندازی:
```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت فایل تکی نهایی برای استفاده آفلاین
npm run build
```

پس از ساخت با `npm run build`، یک فایل یکپارچه `homepage.html` در ریشه پروژه ایجاد می‌شود که تمام فایل‌های جاوااسکریپت و استایل‌ها به صورت خودکار در آن جاسازی (Embed) شده‌اند.

## ⚙️ اجرای خودکار در استارتاپ ویندوز (Windows Startup)

برای اینکه با هر بار روشن شدن سیستم، سرور صفحه خانگی به صورت کاملاً بی‌صدا و مخفی (بدون نمایش پنجره سیاه CMD) اجرا شود:

1. کلید‌های ترکیبی `Win + R` را روی کیبورد فشار دهید.
2. در پنجره باز شده عبارت `shell:startup` را تایپ کرده و Enter بزنید تا پوشه Startup ویندوز باز شود.
3. روی فایل **`AutoRunner.vbs`** در همین پوشه راست‌کلیک کرده و گزینه **Create Shortcut** (ایجاد میانبر) را بزنید.
4. شورت‌کات ایجاد شده را به داخل پوشه Startup منتقل کنید.

> **توضیح:** فایل `AutoRunner.vbs` اسکریپت `AutoRunner.bat` را در حالت `Hidden` (بدون باز شدن پنجره ترمینال) در پس‌زمینه اجرا می‌کند.

## 🦊 تنظیم به عنوان صفحه اصلی فایرفاکس با New Tab Override

برای اینکه با باز کردن هر تب جدید در مرورگر فایرفاکس، این داشبورد نمایش داده شود:

1. افزونه رایگان **[New Tab Override](https://addons.mozilla.org/en-US/firefox/addon/new-tab-override/)** را روی فایرفاکس نصب کنید.
2. وارد تنظیمات افزونه شوید (با باز کردن تب جدید یا از بخش Extensions فایرفاکس).
3. یکی از دو حالت زیر را انتخاب کنید:
   - **حالت سرور لوکال (پیشنهادی):**
     - گزینه **URL** را انتخاب کنید.
     - آدرس سرور لوکال خود را وارد کنید:
       ```text
       http://localhost:23156
       ```
   - **حالت فایل محلی (آفلاین بدون سرور):**
     - در تنظیمات افزونه گزینه **Local File** را انتخاب کنید.
     - دکمه Browse را زده و فایل `homepage.html` ساخته شده را انتخاب کنید.
