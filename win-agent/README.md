# Windows Tools Backend Agent

سرویس محلی پایتون برای ارتباط با ویندوز و ارسال وضعیت سیستم و هارد دیسک‌ها به داشبورد فایرفاکس (React).

---

## قابلیت‌ها
- دریافت مشخصات، پارتیشن‌ها، حجم کل، فضای مصرف‌شده، فضای خالی و درصد مصرف تمام درایوها (`C:`, `D:`, `F:`, ...) از هسته ویندوز (بدون وابستگی به کتابخانه‌های خارجی)
- پایش پورت پیش‌فرض `23157` با قابلیت جابجایی خودکار در صورت اشغال بودن پورت
- پشتیبانی کامل از CORS برای اتصال مستقیم از فرانت‌اند

---

## راه‌اندازی در سیستم جدید

1. اطمینان حاصل کنید پایتون ۳ بر روی سیستم نصب است.
2. برای اجرای دستی یا مشاهده لاگ‌ها در محیط ترمینال:
   - فایل `run-agent.bat` را اجرا کنید.
3. برای ثبت خودکار در **استارتاپ ویندوز (Task Scheduler)** تا با هر بار روشن شدن ویندوز در پس‌زمینه اجرا شود:
   - فایل **`setup-startup-task.bat`** را اجرا کنید (ترجیحاً Run as Administrator).
